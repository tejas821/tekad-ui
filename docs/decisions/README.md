# Architecture Decision Records

One decision per file. Concise. Format:

```
Status | Date | Context | Decision | Alternatives | Reason | Consequences
```

Statuses: `Accepted`, `Proposed`, `Proposed — blocked on research`,
`Superseded by ADR-NNN`, `Rejected`.

Never edit a decision in place to change it. Write a new ADR that supersedes it.
