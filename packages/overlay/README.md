# @tekad/overlay

TEKAD's deferred-close top-layer primitive. TEKAD owns the floating layer (ADR-005, ADR-010).

Part of [TEKAD UI](https://tejas821.github.io/tekad-ui/) — an Angular 22, standalone-only, signals-first component library. [Guide](https://tejas821.github.io/tekad-ui/) · [Source](https://github.com/tejas821/tekad-ui/tree/main/packages/overlay)

## Install

```bash
npm install @tekad/overlay
```

Requires Angular `^22.1.0`.

## Usage

TEKAD's deferred-close top-layer primitive (`TekadDeferredOverlay`), used by dialog, select and tooltip. Most apps use it indirectly through those components.
