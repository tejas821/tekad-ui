# @tekad/core

TEKAD foundation. Nothing here may depend on a component package.

Part of [TEKAD UI](https://tejas821.github.io/tekad-ui/) — an Angular 22, standalone-only, signals-first component library. [Guide](https://tejas821.github.io/tekad-ui/) · [Source](https://github.com/tejas821/tekad-ui/tree/main/packages/core)

## Install

```bash
npm install @tekad/core
```

Requires Angular `^22.1.0`.

## Usage

Foundation used by every TEKAD component: unique ids, the live announcer and the forms seams. Secondary entry points:

- `@tekad/core/primitives/identity`
- `@tekad/core/a11y/live-announcer`
- `@tekad/core/forms/field-context`
- `@tekad/core/forms/model-control`

You normally get it as a peer of a component package.
